**Observed**

- Flags: exactly `--geometry WIDTHxHEIGHT` (value), `--auto-open` / `--no-auto-open` (bool; both set →
  `INVALID_ARGUMENT`). Usage line: `ufo-sighting open [--geometry WIDTHxHEIGHT] [--auto-open|--no-auto-open]`.
  `open -- x` → `INVALID_ARGUMENT "open takes no command"`; only the first token after the verb can be
  `--help`/`-h`.
- Trigger path: `main()` checks `resolveTrigger(argv.join(" ")) === "open"` **before** verb dispatch
  (`ufo-sighting.mjs:4427`), so the whole argv being exactly one of `config/ufo.json`
  `sighting.triggers` (`["open the hatch","open ufo sighting","i wanna see the ufos"]`) opens the wall —
  after normalization (trim, lowercase, `\s+`→single space) and **exact** match, no flags possible.
- Config precedence: `terminalLauncher` is consumed (`UFO_SIGHTING_LAUNCHER` env > config;
  `config/ufo.json` value `omarchy-launch-or-focus-tui`); `tmuxSession`/`tmuxWindow`/`twinMaxDepth` are
  **not** consumed — `base.mjs:179-191` fails boot if the config disagrees with the hardcoded
  `SESSION_NAME`/`WINDOW_INDEX`. `autoOpenWall` default comes from config (`true`, source `"config"`);
  `--auto-open`/`--no-auto-open` echo source `"flag"` and are not persisted.
- What it mutates (under `withOperationLock`): `WALL_NOT_OPEN` gate first (only when the session is
  absent AND auto-open is disabled); `loadManifest({create:true})`; `ensureOwnedSession` (create session
  `ufo_sighting` + window `fleet` + the three `@ufo_sighting_*` options, or attest an existing one,
  else `FOREIGN_SESSION`); `reconcileLocked`; `resolveTerminalOnce`; `launchOrFocusAttach` (1 client →
  focus via `hyprctl dispatch focuswindow pid:^(PID)$`; 0 → launch terminal with `UFO_SIGHTING_ATTACH=1`;
  >1 → `DUPLICATE_CLIENTS`); `waitForOneClient` (cap `UFO_SIGHTING_ATTACH_TIMEOUT_MS` else 10 s, else
  `ATTACH_TIMEOUT`); geometry resolution; `applyLiveLayouts`; `updateSessionStatus` + manifest write.
  `open` never creates a fleet window (`ensureFleetWindow` is launch/register-only).
- Returns: the **full `getStatus` payload** (pretty JSON), not an `{ok:true}` envelope.
  `status: "attached"|"detached"|"invalid"` is client-attachment, not mission liveness.
- Geometry precedence: `--geometry` → `source:"override"`; else attached terminal (hyprland) size →
  `"hyprland-client"`; else `"tmux-client"`; else cached. Profile is a pure ratio test at `37/18`
  (`16:9` rows 3×cols 5 → cap 15; `21:9` → cap 18). The resolved geometry (including `source`) is
  **persisted** into the manifest, so `--geometry` is not a one-shot hint. `1x1` is valid grammar.
- Live: window `1 fleet` (overview strip `%2` + `__idle` keeper `%0`) and window `2 shokunin` (8 mission
  panes); session options `@ufo_sighting_protocol ufo-sighting-wall-v1`,
  `@ufo_sighting_owner /home/vgpnk/Projects/ufo-fsd-alpha`, `@ufo_sighting_wall_id 26da1020-…`.
- Idempotence (test-pinned, `tests/ufo-sighting.test.js:1092-1105`): a second `open` launches no second
  terminal, resolves no second terminal, keeps `wallId`.
