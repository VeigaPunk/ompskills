- `OMP_WORKTREE_DIR` is the only worktree-scoped env var (3 hits: token table, reader, config description); it is absent from the embedded `environment-variables.md`.
- `worktree-cli.ts`: `list` and `clear` enumerate ONLY the single global managed root (`Ste()`), reading it with `readdir`; `clear`'s default filter keeps entries with a defined `orphanReason` (`e.all ? t : t.filter(a=>a.orphanReason!==undefined)`); a dry run returns `{removed:0,failed:0}` without touching the filesystem. Other verbatim `orphanReason` values: `'empty directory'`, `'no recognizable worktree contents'`, `'malformed .git file (no gitdir line)'`, `'parent repo no longer tracks this worktree'`, `'parent repo missing'`.
